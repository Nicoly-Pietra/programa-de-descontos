# 💰 Programa de Descontos

Sistema desenvolvido em **Python** para calcular automaticamente descontos de acordo com o valor de uma compra.

## 📌 Sobre o projeto

O **Programa de Descontos** foi desenvolvido como um projeto prático para aplicar conceitos básicos de programação em Python, principalmente **entrada de dados, estruturas condicionais, cálculos matemáticos e saída de informações**.

O sistema recebe o valor de uma compra e verifica automaticamente qual percentual de desconto deve ser aplicado. Em seguida, calcula o valor do desconto e apresenta o **valor final da compra**.

## ⚙️ Como funciona

O desconto é definido de acordo com o valor da compra:

| Valor da compra            | Desconto |
| -------------------------- | -------: |
| Menor que R$ 200,00        |       5% |
| De R$ 200,00 até R$ 299,99 |      10% |
| R$ 300,00 ou mais          |      15% |

### 🧮 Exemplo

Se o cliente realizar uma compra de **R$ 250,00**, o sistema aplicará **10% de desconto**:

* Valor da compra: **R$ 250,00**
* Desconto: **R$ 25,00**
* Valor final: **R$ 225,00**

## ▶️ Como executar o projeto

1. Instale o **Python 3** no computador.
2. Baixe ou clone este repositório.
3. Abra o **PowerShell** ou outro terminal.
4. Acesse a pasta onde o arquivo está localizado.
5. Execute o comando:

```bash
py desconto.py
```

6. Digite o valor da compra quando solicitado.
